**Clone repo**

```bash
   git clone <GitHub Url>
   ```

**Create new branch and push**

```bash
   git checkout -b <branch name>
   ```

```bash
   git add .
  git commit -m "description"
  git push origin <branch name>
   ```

**change branch**

```bash
   git switch <branch name>
   ```

**or**

```bash
  git checkout <branch name>
   ```


**pull latest changes**

```bash
   git pull origin <branch name>
   ```
```bash
   git pull
   ```
```bash
   git fetch
   ```
